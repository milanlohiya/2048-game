# 2048 Game

A sliding number puzzle game played on a 4x4 grid. Slide tiles up, down, left, or right to merge matching numbers and combine them until you create the **2048** tile (or keep playing for a higher score).

## How to Play
- **Move tiles:** Use the **Arrow keys**, **WASD**, or **swipe** on touch screens.
- **Merge numbers:** When two tiles with the same number touch, they merge into one tile with their sum.
- **New tile spawns:** After each move, a new `2` or `4` tile appears in an empty spot.
- **Win / Game Over:** Reach `2048` to win, and keep going for higher scores until no valid moves remain.

## Features
- Smooth tile movement and merging logic
- Current score and best score tracking
- New game / restart option
- Responsive layout for desktop and mobile
